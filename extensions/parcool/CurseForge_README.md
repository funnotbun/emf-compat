# EMF Compat: ParCool

<!-- ![Wall run](CDN_GIF_URL) -->

A small client-side mod that makes **[ParCool!](https://www.curseforge.com/minecraft/mc-mods/parcool)** animations work correctly with **[Entity Model Features](https://www.curseforge.com/minecraft/mc-mods/entity-model-features)** player models.

Without it, EMF resource-pack animations can override ParCool's parkour poses. With this addon, vaults, wall runs, rolls, climbing and other moves look the way they should and, in some scenarios, even better.

Tested with **[Fresh Animations: Player Extension](https://www.curseforge.com/minecraft/texture-packs/fa-player-extension)**. But should also work with other player animation packs.

## Features

- Supports all ParCool moves.
- Works with ParCool 3.4.x and 4.x.
- Works for your character and other players.
- Keeps unrelated resource-pack animations playing where possible.
- Smooth transitions between ParCool moves and resource-pack animations in ParCool 4.
- Compatible with animations from **[Better Combat](https://www.curseforge.com/minecraft/mc-mods/better-combat-by-daedelus)**, **[Immersive Melodies](https://www.curseforge.com/minecraft/mc-mods/immersive-melodies)** and **[Not Enough Animations](https://www.curseforge.com/minecraft/mc-mods/not-enough-animations)**.
- Cross-Compat with other EMF Compat Extensions.
- Does not change your first-person view.

## Fresh Animations module

The mod includes an optional animation module for **[Fresh Animations: Player Extension](https://www.curseforge.com/minecraft/texture-packs/fa-player-extension)**, made with **[FreshLX's](https://modrinth.com/user/FreshLX)** permission.

This pack gives ParCool moves animations that match the Fresh Animations style, including fast running, jumping, ledge and bar movement, climbing, crawling and swimming.

To use it, enable **EMF Compat: ParCool Animations** in the resource-pack list and place it **above FA+Player**.

## Config

Open **Mods → EMF Compat Core → Config → ParCool**.

- **EMF compatibility:** enables or disables the addon.
- **Pose scope:** choose whether ParCool controls the whole pose or only the limbs.
