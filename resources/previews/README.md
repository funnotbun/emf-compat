# EMF Compat preview media

Animated WebP previews for EMF Compat project pages on Modrinth.

All previews use a 1080 × 700 canvas, 15 FPS and an infinite loop.

## Raw URL

After pushing this directory to GitHub, use:

```text

```

